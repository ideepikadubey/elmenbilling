# Elmen Billing Backend

This directory contains the Node.js + Express + MongoDB backend service.

## Installation

1. Navigate to the `server` directory:
   ```bash
   cd server
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure the `.env` file with your MongoDB Connection string (defaults to `mongodb://localhost:27017/elmen_billing`).

## Starting the Server

- Production: `npm start`
- Dev mode (auto-reload): `npm run dev`
